# Example Addon Setup Guide

## Steps

- **Download** the `example` directory.
- **Copy** the `example` directory to your Dota 2 folder:  
  `C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta\game\dota_addons\example`
- **Launch** Dota 2.
- **Enable** the console in the *Settings* menu.
- **Open** the console and type:  
  `dota_launch_custom_game example dota`

## Result

After running the `dota_launch_custom_game example dota` command, you should see the following message:

**"Hello World from Tisza!"**
